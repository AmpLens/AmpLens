# Five-point Yang–Mills inputs

The files `YM_5pt_form0.txt` through `YM_5pt_form1023.txt` contain the 1,024 Feynman-diagram expressions of the five-point Yang–Mills set used in the paper, one expression per file. They differ only in the assignment of polarization reference spinors to the external legs. Each expression is equal on shell to the Parke–Taylor form

```text
ab(1,2)**3/(ab(1,5)*ab(2,3)*ab(3,4)*ab(4,5))
```

Of the expressions provided by the authors, 512 equal the negative of the form above. We multiplied these expressions by −1 so that all inputs equal that form.
